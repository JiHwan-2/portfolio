Project 02

AI 지능형 CCTV 시스템

YOLO 객체 인식 기반 4대 핵심 기능 구현

단순 녹화를 넘어 AI가 상황을 판단해 관리자에게 알리고 자동으로 증거 영상을 확보하는 지능형 보안 시스템입니다. 2인 팀 프로젝트, 팀장(조장)으로 시스템 설계와 4개 핵심 기능 전체를 구현했습니다. (2025.12)

PythonFlask YOLOv8sOpenCVThreading
👥

인파 밀집 감지 및 경고

YOLOv8로 Person 클래스를 실시간 카운팅해 밀집 상황을 판단.

  • classes=[0, 67] 필터링으로 추론 성능 최적화
  • conf=0.3 임계값으로 오인식 감소
  • 사람 3명 이상 시 danger 플래그 활성화
⚠️

위험물 식별 및 경고

지정 물체(대체 클래스) 등장 시 즉시 식별하고 시각적으로 경고.

  • OR 조건 위험 판단 (인파 또는 위험물 중 하나만 만족)
  • blink_rate로 화면 점멸 효과
  • cv2.addWeighted로 반투명 오버레이 경고
🎥

이벤트 자동 녹화

위험 상황 발생 시 자동 녹화 시작, 종료 후에도 버퍼 유지.

  • danger 플래그 True 전환 시 새 파일 생성
  • 타임스탬프 기반 파일명, avc1(H.264) 코덱
  • 위험 종료 후 3초 버퍼로 후속 장면 보존
📡

웹 스트리밍 대시보드

별도 프로그램 설치 없이 브라우저에서 실시간 모니터링.

  • Flask MJPEG 스트리밍 (multipart/x-mixed-replace)
  • Lock으로 AI 스레드-웹 스레드 간 동기화
  • Yield Generator로 지속적 프레임 전송
