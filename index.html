Project 03

스마트 IoT 가습기 제어 시스템

소켓 통신 기반 실시간 제어 및 모니터링

15바이트 고정 길이 패킷을 TCP/IP 소켓 위에서 직접 설계해, 라즈베리파이(하드웨어)와 안드로이드 앱(클라이언트) 간 신뢰성 있는 양방향 통신을 구현했습니다. 2인 팀 프로젝트, 팀장(조장)으로 통신 프로토콜 설계와 서버 로직을 전담했습니다. (2025.12)

📦

통신 프로토콜 직접 설계

STX/ID/Data/ETX 구조의 15바이트 패킷을 정의하고 C 구조체로 구현.

  • __attribute__((packed))로 패딩 없는 정확한 바이트 정렬
  • Union(StEntity)으로 4바이트 Data 영역 유연하게 활용
  • Kotlin ByteBuffer로 C(Little Endian)-Java(Big Endian) 엔디안 차이 처리
🌡️

센서 데이터 수집

DHT11 센서를 소프트웨어적으로 직접 제어해 40비트 신호 처리.

  • GPIO 핀 Output→Input 모드 전환
  • micros() 단위로 High 유지시간 측정해 0/1 판별
  • 습도·온도·체크섬 5바이트 버퍼 구성
🧵

멀티스레드 타이머

pthread로 메인 서버 루프를 막지 않는 비동기 타이머 구현.

  • pthread_create로 별도 실행 흐름 생성
  • 조건 충족 시 pthread_cancel로 즉시 스레드 종료
  • 센싱·통신과 독립적으로 동작
🛑

오동작 방지 로직

습도 상한값과 실시간 습도를 비교해 불필요한 명령을 소프트웨어적으로 차단.

  • 전역 변수(g_humi_limit)를 모든 스레드가 공유
  • 과습 상태에서 ON 요청 자동 차단
  • 에너지 절약형 자동 종료
팀 프로젝트 고찰
