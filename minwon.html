Project 01

AI민원길잡이 — 생활 불편을 민원으로 바꿔 주는 AI Agent

평소 말투로 말하면 담당 기관과 민원 초안까지

시민이 생활 불편을 평소 말투로 입력하면 AI Agent가 문제를 분석하고, 부족한 정보를 되묻고, 관할 기관을 찾아 민원 초안을 작성·검증합니다. 최종 민원은 시민이 확인하고 고친 뒤 직접 제출합니다. 제4회 경남 AI·SW 경진대회 대학부 출품작 (2026.09.29 ~ 10.06, 2인 팀, 팀장·AI Agent 개발 담당).

My Role — 팀장 · AI Agent 개발

🧭

설계 · Agent 골격

문제 정의와 Workflow 설계서를 쓰고 LangGraph로 단계별 Agent를 구현.

  • 단계별 출력 구조 강제
  • 정보가 부족하면 최대 2회 추가 질문
  • AI 실패 시 규칙 엔진으로 그 단계만 대체
🗺️

Tool 연결

카카오 로컬 API로 위치를 확인하고 관할 기관을 검색.

  • 담당 부서·창구·절차 지식베이스
  • 재시도·대체 경로
  • 위치 후보가 여러 곳이면 시민이 선택
✍️

초안 작성 · 검증

담당 기관 판단 후 민원 초안을 쓰고, 문제가 있으면 다시 작성.

  • 연락처·개인정보·위치·분량 규칙 검사 + AI 검토
  • 근거 없는 '필수' 증빙은 '권장'으로 조정
  • 수정 요청은 요청한 부분만 반영
🛡️

안전 장치

AI가 틀리면 안 되는 부분은 정해진 규칙으로 처리.

  • 개인정보 가림, 지시 주입(프롬프트 인젝션) 감지
  • 위기 표현에 자살예방 상담전화 109 안내
  • 상담 창구 연락처는 확인된 데이터에서만
🌏

다국어

한국어·영어·중국어·베트남어로 대화와 안내를 제공.

  • 민원 초안은 한국어 원문 + 시민의 언어 번역본
  • 화면 글자 4개 언어, 시민의 언어로 자동 전환
📏

정확도 평가

정답을 붙인 평가 세트와 실행 스크립트를 직접 구축.

  • 같은 평가를 3회 반복해 결과 흔들림 측정
  • 회차별 결과 비교 모드
  • 틀린 문항의 원인을 고친 뒤 다시 측정

팀원 담당 기능: 현장 사진 첨부(촬영 위치로 기관 찾기), 민원 서비스 안내(서류 발급·신고), 비슷한 민원 사례 원문 링크

검증 결과

구분결과내용
입력 확인132/132민원·다른 창구·불분명·민원 아님·안전 판단
대화 도중 판단61/61이어지는 말·다른 민원·관계없는 말 구분
담당 기관 (처음부터 끝까지)11/11경남 7개 시 실제 장소, 초안 검증까지 통과
수정 요청20/20따르면 안 되는 요청 7개 포함
다국어 엉뚱한 입력60/60영어·중국어·베트남어 지시 주입·장난 입력
자동 테스트193건실제 AI·외부 API를 부르지 않는 pytest

문제 해결 사례

📍

위치 검색 오류 6곳 → 0곳

'창신대 버스정류장'을 검색하면 노무법인이 나오는 문제. 결과가 없으면 검색어를 줄여 다시 찾고, 이름이 다른 결과는 버리게 해 경남 장소 22곳의 관할 오류를 없앰.

🏛️

시청 검색 정확도

가까운 순으로 찾으면 '○○시청점' 같은 가게가 먼저 나와 경남 8곳 중 4곳에서 청사를 놓침. 이름 정확도 순 검색으로 변경.

🔒

다국어 지시 주입

평가에서 중국어·베트남어 지시 주입을 감지하지 못하는 문제를 찾아 감지 규칙을 보완, 60문항 모두 통과.

📝

수정 요청 처리

따를 수 없는 요청을 이유 없이 무시하던 문제. 반영하지 않은 이유를 시민의 언어로 알리고 요청한 부분만 고치게 해 20/20.
